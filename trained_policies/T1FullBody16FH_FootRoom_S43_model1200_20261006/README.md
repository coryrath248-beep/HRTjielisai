# FootRoom S43 第 1200 轮：高速直行仿真里程碑

这是用户于 2026-10-06 选定保存的全身行走仿真里程碑。`model_1200.pth` 是 80 维观察、21 关节动作的 PPO 检查点，SHA256 为 `944d8cc258ba746ba27b01c53690eb518cbc24962944974faf7229f33c53a238`。`T1FullBody16FH_FootRoom_S43.yaml` 为对应训练配置；`evaluations/` 保存原始结果。

固定 1.6 m/s 直行命令、MuJoCo 60 秒走满：后半程实速 **1.521 m/s**，累计横漂 **+0.067 m**，全身力矩请求触限物理步占 **10.6%**，URDF 关节速度触限 **0%**，左/右支撑脚朝向分别 **+0.158/−0.059 rad**。这些都是仿真指标，力矩触限不是实机电机读数。Isaac Gym 随机地形种子 42/44、每颗 64 环境、30 秒存活分别为 61/64、62/64；存活环境的后半程速度为 1.542/1.545 m/s，力矩触限为 21.3%/21.5%。

`videos/` 的斜前、正面、侧面视频均由**这个检查点**在 MuJoCo 中以固定 1.6 m/s 命令重新录制，每段 15 秒。视频本身不是 60 秒量测；对应的 60 秒数值以 `evaluations/T1FullBody16FH_FootRoom_S43_model1200_vx16_60s.json` 为准。

策略的仿真命令有三个独立分量：前进速度 `vx`、侧向速度 `vy`、转向角速度 `yaw`，可以同时给 `vx` 和 `yaw`。平地 Isaac Gym 初测中，`vx=0.8 m/s` 加 `yaw=+0.2/−0.2 rad/s` 时实际偏航角速度约 +0.129/−0.177 rad/s；原地 `yaw=+1.0/−1.0` 时约 +0.606/−0.832 rad/s。原地 +0.4 指令仅约 +0.026 rad/s，转向响应仍不对称。模拟手动纠偏时，松开转向键必须把相对直线路径的起点和航向重设为当前状态；沿用旧参考会引起回拉和跌倒。原始数据在 `evaluations/FootRoom1200_plane_*.json`。

这是**训练与评估里程碑，不是可直接部署的实机程序**。仓库 `train_kit/deploy` 仍使用旧的 47 维观察、12 腿动作接口；它虽然允许同时给前进和转向命令，却不能加载此 21 动作策略。实机还需核对 80 维观察、21 关节映射、控制频率、限幅、相对路径参考重设、手柄方向与停机方式。此前的 PathStride 实机交接包未被此目录替换。
