这些数值来自仿真。训练与评估源码保存在本地项目 `RL训练/booster_gym_fullbody/`；本仓库现有 `train_kit/deploy` 仍是 47 维观察、12 动作的旧接口，不能直接加载这两个检查点。新策略另需与训练一致的 80 维观察、21 关节顺序、控制频率与增益，其中末尾两维是相对直行命令起点的横向偏差与航向误差。实机端尚未核对这些信号和映射，也未完成低速安全验收。摇杆前推目前仍调用机器人已有的行走控制，不会自动切换到本策略。

补充的 30 秒诊断在 `evaluations/*symmetry_vx16_30s.json`：两版相位对齐的左右腿关节角 RMS 差为 0.3327/0.3343 rad，髋偏航差异最大；两脚步频与步长接近。种子 42 的 MuJoCo 力矩请求触限主要集中在左、右踝俯仰，分别占各自关节物理步的 6.26% 和 4.89%。这些指标可用于下一版比较，不能单凭视频判断真机左右硬件是否有差异。

训练输出的 `.pth` 含 actor、critic 与优化器状态；导出 actor 的脚本是全身训练源码里的 `export_model.py`。请按文件名与 SHA256 选定检查点，不使用自动选择“最新”模型的方式部署。
